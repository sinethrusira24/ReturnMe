# ReturnMe 🔍🎒

--Centralizing Item Reporting, Connecting Owners on Campus--

ReturnMe is a smart web platform built to centralize lost-and-found operations. It is specifically designed for university environments to help staff and students easily search listings and submit secure ownership claims to retrieve their belongings.

---

🚀 The Problem

* Fragmented Information: Lost items are often scattered across different department offices and security desks, making it difficult for students to know where to
  look.
* Manual Verification Failure: Processing ownership claims relies on inefficient, verbal verification instead of a streamlined digital process.
* Communication Gaps: Finders often lack a quick, centralized way to report items they have discovered on campus grounds.

---

## 💻 Tech Stack
* HTML5, CSS3, JavaScript
* Firebase
